# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

Three vendored research projects sit side by side. **`anydepth-yolov12/` is the active project** — work there unless told otherwise.

- `anydepth-yolov12/` — YOLOv12 + AnyDepth skip-layer self-distillation (a fork of Ultralytics). This is where current development happens.
- `anydepth-rt-detr/` — RT-DETR with the same AnyDepth idea (separate codebase, RTDETR/Deformable-DETR style; `tools/train.py` + YAML configs).
- `DynamicDet/` — original CVPR'23 DynamicDet (Dy-YOLOv7). The AnyDepth router (`AdaptiveRouter`) was ported from here.

All commands below assume `cd anydepth-yolov12`.

## Setup

```bash
pip install -r requirements.txt
pip install -e .
```

Edit `ultralytics/cfg/datasets/bdd100k.yaml` to point to local BDD100K paths before training. Weights live in `./pretrained_coco/` (COCO-pretrained, used as `--weight` for fine-tuning) and `./finetuned_bdd100k/` (BDD100K checkpoints, used for validation).

## Common commands

Fine-tune on BDD100K (2 GPUs; hyperparameters are hardcoded in `train_adn_bdd100k.py`, not exposed as flags):

```bash
export CUDA_VISIBLE_DEVICES=0,1
python -m torch.distributed.run --nproc_per_node 2 train_adn_bdd100k.py \
  --task detect --data bdd100k.yaml --epoch 30 --imgsz 1280 \
  --config ./ultralytics/cfg/models/v12/yolo-ad-v12-orig.yaml \
  --weight ./pretrained_coco/yolo-ad-small_0.479_0.451.pt \
  --project ./runs/bdd100k/detect/anydepth-yolov12s
```

Resume: add `--resume` and point `--weight` at `<project>/train/weights/last.pt` (omit `--config`).

Validate (single GPU). For AnyDepth weights this auto-runs both **Full** (no skips) and **Base** (all layers skipped); for baseline weights it runs once:

```bash
python val_adn_bdd100k.py --imgsz 1280 \
  --weight ./finetuned_bdd100k/anydepth-yolov12s.pt \
  --project ./runs/bdd100k/detect/anydepth-yolov12s/val
```

Always pass the same `--imgsz` used for training (1280 for BDD100K). `rect=True` is used because BDD100K is 1280×720.

COCO training uses the separate `train_adn_coco.py` / `train_nano_adn_coco.py` scripts. Upstream Ultralytics tests still exist under `tests/` (`pytest tests/`).

## AnyDepth architecture

AnyDepth turns one network into a nested **SUPER** / **BASE** detector pair that share weights, trained jointly with skip-layer self-distillation.

- **Skippable modules** (`ultralytics/nn/modules/block.py`, `conv.py`): `SkippableC3k2`, `SkippableA2C2f`, `SwitchableC3k2`, `SwitchableC2f`, `SwitchableA2C2f`, `SwitchableConv`. Each `forward(x, skip)` runs either the full block or a reduced "base" subset (e.g. only `n_shared_blocks`, with channel-count adjustments propagated to `cv2`). The model YAMLs in `ultralytics/cfg/models/v12/` (`yolo-ad-*.yaml`) wire the backbone/head out of these modules; `yolov12.yaml` is the plain baseline.
- **`DetectionModelAnyDepth`** (`ultralytics/nn/tasks.py`): subclass of `DetectionModel`. `_predict_once` walks `self.model` carrying a `skip` list (one bool per skippable layer); `SwitchableConv` reuses the next skippable layer's flag. `num_skippable_layers` counts these modules. `init_criterion` returns a `(v8DetectionLoss, DetectionLossAnyDepth)` pair.
- **Training loop** (`DetectionTrainerAnyDepth` in `ultralytics/models/yolo/detect/train.py`): each step forwards twice — `skip_super=[False]*N` and `skip_base=[True]*N` — then `loss = alpha_base * loss_base + (1 - alpha_base) * loss_kd * kd_scale`. `alpha_base` is set in `train_adn_bdd100k.py` (default `1.0`). Validation runs the Super pass and optionally logs Base/FLOPs.
- **Router (Step 2+)**: `AdaptiveRouter` (`ultralytics/nn/modules/router.py`) is a tiny per-image scorer attached via `attach_router`. It taps the last shared layer's feature (`ROUTER_TAP_LAYER = 1`) and emits a score in [0,1]; `_predict_dynamic(x, dy_thres)` routes each sample (batch_size=1 only) to SUPER or BASE. This enables variable-speed inference like DynamicDet.

## Task routing

`YOLO(path, task=...)` dispatches via `task_map` in `ultralytics/models/yolo/model.py`. Loading any config/weight whose stem contains `yolo-ad` constructs a `YOLOv12AnyDepth` model and switches to the AnyDepth task map. Task names:

- `detect` — standard; AnyDepth map → `DetectionModelAnyDepth` + `DetectionTrainerAnyDepth` + `DetectionValidatorAnyDepth`.
- `detect_step2` — router training.
- `detect_wst` — detection **plus** attribute classification (weather / scene / timeofday) for BDD100K. Code lives in `ultralytics/models/yolo/detect_wst/` with `DetectionWSTModel` / `DetectionWSTModelAnyDepth`, `DetectionWSTDataset`, and an extended loss (`weather_loss`, `scene_loss`, `timeofday_loss`). Attribute JSON is generated by `ultralytics/cfg/datasets/gen_bdd100k_attributes_json.py`.

When adding behaviour, mirror the existing `*AnyDepth` / `*WST` subclass pattern rather than editing the upstream base classes.
